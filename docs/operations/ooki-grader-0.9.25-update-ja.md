# Ooki Grader 0.9.25　ホストPCの更新手順

1. 採点・取り込み・配信を終えてから、ホストPCでZIPをダウンロードし、右クリックして「すべて展開」を選びます。[Windowsホスト更新用ZIP](https://github.com/toshizo-link/ookigrader/releases/download/v0.9.25/OokiGrader-0.9.25-Windows-Host-Update.zip)
2. 展開したフォルダー内の `01-Update-OokiGrader-Host.cmd` を右クリックし、「管理者として実行」を選びます。更新先が **0.9.25** であることとバックアップの状態を確認して進めます。
3. `Ooki Grader host update completed successfully.` と表示されたら、いつものURLでOoki Graderを開きます。

**途中で止まったひな形**は、「テストひな形」から以前の生成状況を開き、「失敗した項目を再試行」を押してください。AI側で利用上限や一時エラーが続く場合は、画面に出る案内に従って時間を置いてください。

更新後の試行で「AIサービス側で処理を完了できませんでした」と出た場合は、サービス側のエラーです。利用上限に達した場合は「AIの利用上限に達しました」と表示されます。

**新しい表示を確認するには**、採点結果から結果PDFを作成してください。均一配点の暗記テストでは、右端に各問の正誤が表示されます。すでにダウンロードしたPDFには、作成時の表示が残ります。
