# Ooki Grader 0.9.23　スクマネの配信文と採点結果PDF

- スクマネで自動送信するメッセージの状況が「解決済」になります。
- 個人の採点結果を送る本文に、教科・テスト名・合否が入ります。「管理」→「スクマネ配信」で、合格・不合格・合否基準未設定のそれぞれの文面を編集できます。
- 採点結果PDFの先頭に成績表が入り、その後に答案が元のページ順で続きます。成績表の「採点日」には、先生が採点を確定した日を日本時間で表示します。
- 答案受付を始めるときの「実施日」は任意です。模試など日付を記録したいテストで入力してください。
