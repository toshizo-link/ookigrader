# Ooki Grader 0.9.24　ホストPCの更新手順

1. 採点・取り込み・配信の操作を終えてから、ホストPCでZIPをダウンロードし、右クリックして「すべて展開」を選びます。[Windowsホスト更新用ZIP](https://github.com/toshizo-link/upgraded-ooki-grader/releases/download/v0.9.24/OokiGrader-0.9.24-Windows-Host-Update.zip)
2. 展開したフォルダーの `01-Update-OokiGrader-Host.cmd` を右クリックし、「管理者として実行」を選びます。更新先が **0.9.24** であることとバックアップの状態を確認して進めます。
3. `Ooki Grader host update completed successfully.` と表示されたら、いつものURLでOoki Graderを開きます。

## 合格基準をひな形に設定する

ひな形を開き、「合格基準」でミスの上限を入力して保存します。たとえば「4ミスまで合格」なら、4ミスで合格、5ミスで不合格です。そのひな形で次に始めるテスト実施から適用されます。すでに始めたテストは、その実施の設定で基準を変更できます。

## スクマネの配信文を編集する

管理者で「管理」→「スクマネ配信」を開きます。件名は全判定共通です。合格・不合格・合否基準未設定を切り替えて本文を編集し、プレビューで確認して保存します。教科・テスト名・合否は件名にも本文にも差し込めます。固定の文章だけでも送れます。

0.9.23で独自の文面を保存していた場合は、以前の見出しを含む全文を引き継ぎます。標準のままだった文面には、この版の暗記テスト用の文面が入ります。
