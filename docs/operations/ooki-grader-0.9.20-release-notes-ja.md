# Ooki Grader 0.9.20　School Managerの自動配信を修正

スクマネのログイン画面や宛先の検索結果が表示されるまで待つようにしました。生徒番号と氏名で宛先を確認し、添付したPDFのファイル名が画面に表示されてから送信します。

Windows版Edgeでスクマネの実際のログイン画面を確認しました。試験環境では、対象の保護者の模擬受信箱に採点結果PDFが1件届き、送信直後に通信が途切れても二重送信されないことを確認しました。学校のアカウントでの受信は、新しいダミー答案1件でご確認ください。
