# Ooki Grader 0.9.23　ホストPCの更新手順

1. 採点・取り込み・配信の操作を終えてから、ホストPCにZIPをダウンロードし、右クリックして「すべて展開」を選びます。[Windowsホスト更新用ZIP](https://github.com/toshizo-link/upgraded-ooki-grader/releases/download/v0.9.23/OokiGrader-0.9.23-Windows-Host-Update.zip)
2. 展開したフォルダーの `01-Update-OokiGrader-Host.cmd` を右クリックして「管理者として実行」し、更新先が **0.9.23** であることとバックアップの状態を確認して進めます。
3. `Ooki Grader host update completed successfully.` と表示されたら、いつものURLでOoki Graderを開きます。
4. 配信文を変えたい場合は、管理者で「管理」→「スクマネ配信」を開きます。合格・不合格・合否基準未設定の文面を編集して保存します。教科・テスト名・判定は自動で本文に入ります。
