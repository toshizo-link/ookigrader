# Ooki Grader 0.9.24　ひな形の合格基準とスクマネの配信文

- ひな形ごとに「4ミスまで合格」のように基準を保存できます。次にそのひな形でテストを始めると、基準が自動で入ります。
- 「管理」→「スクマネ配信」で、共通の件名と、合格・不合格・合否基準未設定の本文を全文編集できます。教科・テスト名・合否は好きな位置に差し込めます。
- 初期の件名は「暗記テスト採点結果のお知らせ」です。合格時は次の範囲への励まし、不合格時は再テストの案内が入ります。
